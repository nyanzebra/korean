# Korean Grammar Study Plan

A suggested path through this vault, loosely following TOPIK I → II → intermediate/advanced
progression. Check off items as you cover them. Beginner items live in
`00-기초 필수 문법/`.

## Stage 1 — Absolute basics (TOPIK I, foundational particles & endings)
Goal: sentence structure, basic particles, present/past tense, simple connectors.

- [ ] 은/는 vs 이/가
- [ ] 을/를, 에, 에 vs 에서
- [ ] 도, 만 vs 뿐 → [[만 vs 뿐]]
- [ ] 았/었 (past tense)
- [ ] 고 있다 (progressive)
- [ ] 아/어 있다 (resultative)
- [ ] 안/못/지 않다/지 못하다 (negation)
- [ ] (으)ㄹ 수 있다/없다 → then [[을 수도 있다]], [[ㄹ 수밖에 없다]]
- [ ] (으)면 (basic conditional) → then Stage 3 conditionals
- [ ] 아서/어서 (basic reason/sequence) → then [[여서]], [[서 vs 으니까]]
- [ ] (으)려고, (으)러 → then [[도록]], [[를 위하다_기를 위하다]]
- [ ] 부터 & 까지, 밖에, 조차 & 마저 & 까지도
- [ ] (으)로 (basic) → then [[로서_로써_로 인하여]]

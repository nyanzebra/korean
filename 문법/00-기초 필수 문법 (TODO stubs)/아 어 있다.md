## 아/어 있다 #card
?begin
### Usage
Expresses a resultant state — the subject is in a state that resulted from a prior completed change
(usually with intransitive/change-of-state verbs like 앉다, 서다, 눕다, 열리다, 닫히다, 죽다, 살다).
Contrasts with [[고 있다]], which usually describes an action actively in progress.
### Form
| Verb stem vowel | Ending |
| --- | --- |
| ㅏ, ㅗ | -아 있다 |
| other vowels | -어 있다 |
| 하다 | -해 있다 (rare — 하다 verbs usually use 고 있다 instead) |
### Restrictions
- Mostly used with intransitive verbs describing a change of position/state (앉다, 서다, 눕다, 가다,
  오다) or passive/change verbs (열리다, 닫히다, 켜지다, 꺼지다).
- Not usually used with plain transitive action verbs — those take 고 있다 instead.
### Examples
* 의자에 앉아 있어요.
	* I am sitting in the chair (resultant state after sitting down).
* 문이 열려 있어요.
	* The door is open (as a result of having been opened).
* 불이 꺼져 있어요.
	* The light is off (as a result of being turned off).
* 그 사람은 벌써 도착해 있었어요.
	* That person had already arrived (and was there).
* 나무가 죽어 있어요.
	* The tree is dead (in the state of having died).
### Notes
Rule of thumb: 고 있다 = "doing X" (ongoing action); 아/어 있다 = "having become X and still being
that way" (resultant state). Compare 서 있다 (standing, a state) vs 서고 있다 (which sounds odd/rare,
since 서다 is more naturally a change-of-state verb).
?end

## (이)라서 #card
?begin
### Usage
Same as `서` grammar but used with nouns: "because (it) is N". It is the noun + 이다 version of [[아서_어서]] / [[여서]].
### Form
- N이라서 (noun ending in a consonant): 학생이라서
- N라서 (noun ending in a vowel; 이 is usually dropped): 친구라서
### Restrictions
- Like 아서/어서, it cannot be followed by commands or suggestions; use [[으니까]] (N(이)니까) instead.
### Examples
* 학생이라서 할인을 받았어요.
	* Because I'm a student, I got a discount.
* 휴일이라서 사람이 많아요.
	* It's a holiday, so there are a lot of people.
* 제 친구라서 믿을 수 있어요.
	* He's my friend, so I can trust him.
### Notes
- See [[서 vs 으니까]] for the reason-connective comparison.

?end

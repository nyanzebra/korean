## (을/를) 취급하다 #card
?begin
### 뜻
- to treat (as in "to handle / to regard as")
- to handle (things)
### 예
- 이 물건은 깨지기 쉬우니까 조심해서 취급해 주세요
  - This item is fragile, so please handle it with care
- 그는 저를 어린아이처럼 취급해요
  - He treats me like a child
### Notes
- Used mainly for things (goods, materials) or for regarding someone/something "as" something; for people's behavior toward others, see (을/를) 대하다
- Related: 다루다 (to handle, deal with)
?end

## 부하 #card
?begin
### 뜻
- load, burden (負荷)
### 예
- 기계에 너무 큰 부하가 걸려서 멈췄어요
  - The machine stopped because too great a load was placed on it
### Notes
- Two different hanja words with the same sound: 部下 (subordinate) and 負荷 (load)
- See also: [[직업과 일]] (other meaning: 部下, subordinate)
?end

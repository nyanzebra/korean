## 후회 #card #vocabulary
?begin
### 뜻
- regret
- repent
- remorse

### 예
- 그 사람일지라도 자신이 한 일에 대해 후회하는 일이 있는 게야
	- Even he regrets some of the things he has done.
- 이제 와서 후회해도 소용이 없다
	- It is no use crying over spilled milk.
- 너는 나중에 후회할 거야
	- You will regret it later.
- 평생 후회할 것 같아요
	- I think I'll regret this for the rest of my life.

### Notes
- 후회하다 (verb): to regret → see the 후회하다 card below
- 유감: regret from a more formal/polite perspective (sorry that something happened)
- Related patterns for expressing regret: 할 수 있었는데 / 해야 했는데 / 해야만 했는데 (below)

?end

## 후회하다 #card #verb #regret #feel-remorse #repent
?begin
### 뜻
- to regret

### 예
- 그 결정을 후회해요.
	- I regret that decision.
- 나중에 후회할 거예요.
	- You'll regret it later.

### Notes
- Noun form: 후회

?end

## 유감 #card #vocabulary
?begin
### 뜻
- regret
- pity
- remorse

### 예
- 그가 본회의에 참석하지 못한다는 것은 유감스러운 일이다
	- It is deplorable [regrettable] that he should be absent from this meeting.
- 나는 유감스럽지만 초대를 거절했다
	- I regretfully declined the invitation.
- 유감이지만 이 프로그램은 중지됩니다
	- I regret [am sorry] to say that this program will be discontinued.
- 그건 유감이에요
	- That's a pity.

### Notes
- 유감입니다: "I regret to say / I'm sorry (to hear that)"
- 유감스럽다 (adjective) → see 감정.md
- 후회 is personal regret over one's own actions; 유감 is more formal regret/pity about a situation

?end

## 할 수 있었는데 #card #vocabulary
?begin
### 뜻
- could have done (but didn't)

### 예
- 할 수 있었는데 하지 않았어요
	- I could have done it, but I didn't.
- 조금만 더 노력하면 할 수 있었는데...
	- I could have done it if I had tried a little harder...

### Notes
- Part of the "3 sad things" set with 해야 했는데 and 해야만 했는데

?end

## 해야 했는데 #card #vocabulary
?begin
### 뜻
- should have done (but didn't)

### 예
- 해야 했는데 못 했어요
	- I should have done it, but I couldn't.
- 어제 전화해야 했는데 깜빡했어요
	- I should have called yesterday, but I forgot.

### Notes
- Part of the "3 sad things" set with 할 수 있었는데 and 해야만 했는데

?end

## 해야만 했는데 #card #vocabulary
?begin
### 뜻
- absolutely should have done (but didn't)
- really had to do (but didn't)

### 예
- 해야만 했는데 못 했어요
	- I really should have done it, but I couldn't.
- 그때 사과해야만 했는데 자존심 때문에 못 했어요
	- I really should have apologized back then, but I couldn't because of my pride.

### Notes
- Stronger/more emphatic than 해야 했는데 (the particle 만 adds emphasis)
- Part of the "3 sad things" set with 할 수 있었는데 and 해야 했는데

?end

---

### Note
From: "인생에서 가장 슬픈 3가지: 할 수 있었는데..., 해야 했는데..., 해야만 했는데..."
(In life there are 3 especially sad things: "I could have done it...", "I should have done it...", "I absolutely should have done it...")

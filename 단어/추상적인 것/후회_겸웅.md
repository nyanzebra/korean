## 후회 #card #vocabulary
?begin
### 뜻
- regret, remorse
### 예
- 후회하다
	- To regret
- 평생 후회할 거 같아요
	- I think I'll regret this for the rest of my life
?end

## 유감 #card #vocabulary
?begin
### 뜻
- regret, pity
### 예
- 유감입니다
	- I regret to say
- 그건 유감이에요
	- That's a pity
?end

## 할 수 있었는데 #card #vocabulary
?begin
### 뜻
- could have done
### 예
- 할 수 있었는데 하지 않았어요
	- I could have done it but didn't
?end

## 해야 했는데 #card #vocabulary
?begin
### 뜻
- should have done
### 예
- 해야 했는데 못 했어요
	- I should have done it but couldn't
?end

## 해야만 했는데 #card #vocabulary
?begin
### 뜻
- should have had to do, must have done
### 예
- 해야만 했는데 못 했어요
	- I should have had to do it but couldn't
?end

---

### Note
From: "인생에서 가장 슬픈 3가지: 할 수 있었는데..., 해야 했는데..., 해야만 했는데..."
(In life there are 3 different really sad things: I could've done, I should've done, should've only done)

## 도와줄 수 있어? #card #help
?begin
### 뜻
- Can you help me?
### 예
- 도와줄 수 있어요?
	- Can you help me? (polite)
- 도와줄 수 있어?
	- Can you help? (casual)
- 이 짐을 옮기는 거 도와줄 수 있어?
	- Can you help me move this luggage?
?end

## 도움이 필요해요 #card #help
?begin
### 뜻
- I need help
### 예
- 도움이 필요해요
	- I need help
- 조금 도움이 필요한데요
	- I need a little help
- 지금 도움이 정말 필요해요
	- I really need help right now
?end

## 내가 도와줄까? #card #help
?begin
### 뜻
- Can I help you? / Would you like my help?
### 예
- 내가 도와줄까?
	- Can I help you? (casual)
- 제가 도와드릴까요?
	- Can I help you? (polite)
- 뭘 도와줄까?
	- What can I help you with?
?end

## 손을 좀 빌려줄 수 있어요? #card #help
?begin
### 뜻
- Can I borrow your hand? / Can you lend a hand?
### 예
- 손을 좀 빌려줄 수 있어요?
	- Can you lend a hand?
- 잠깐 손 좀 빌려 줄래?
	- Can you lend a hand for a moment?
- 많이는 아니고 손을 한번만 빌려주세요
	- I just need a small hand, please help for just once
?end

## 뭘 도와드릴까요? #card #help
?begin
### 뜻
- What can I help you with?
### 예
- 뭘 도와드릴까요?
	- What can I help you with? (formal)
- 뭘 도와줄까?
	- What can I help with? (casual)
- 구체적으로 뭘 도와드릴까요?
	- Specifically, what can I help you with?
?end

## 괜찮으면 도와드릴게요 #card #help
?begin
### 뜻
- If you don't mind, I'll help / If it's okay with you, I can help
### 예
- 괜찮으면 도와드릴게요
	- If you don't mind, I'll help
- 괜찮으시면 내가 도와줄게요
	- If it's okay with you, I'll help
- 괜찮으면 우리가 함께 할까요?
	- If it's okay, should we do it together?
?end

## 혼자 하려고 하지 말고 나한테 말해 #card #help
?begin
### 뜻
- Don't try to do it alone, tell me
### 예
- 혼자 하려고 하지 말고 나한테 말해요
	- Don't try to do it alone, tell me
- 혼자 다 하려고 하니까 힘들어
	- It's hard when you try to do everything alone
- 혼자 하지 말고 도움을 청해
	- Don't do it alone, ask for help
?end

## 힘들어? 도와줄 게 있어? #card #help
?begin
### 뜻
- Are you struggling? Is there anything I can help with?
### 예
- 힘들어? 도와줄 게 있어?
	- Are you struggling? Anything I can help with? (casual)
- 힘들어 보이는데, 도와줄 게 있어?
	- You look like you're struggling, is there anything I can help with?
- 어려워 보이는데 도와줄까?
	- You look like you're having a hard time, can I help?
?end

## 도움이 필요하면 말해 #card #help
?begin
### 뜻
- Tell me if you need help / Let me know if you need anything
### 예
- 도움이 필요하면 말해
	- Tell me if you need help (casual)
- 뭐 필요하면 말해요
	- Let me know if you need anything
- 어려우면 언제든지 도움을 청하세요
	- Ask for help anytime if you're struggling
?end
